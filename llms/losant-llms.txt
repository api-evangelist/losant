# Losant

> Losant is an Enterprise IoT Platform for building connected products: device fleet management, a visual
> workflow engine, edge and embedded compute, time-series telemetry, dashboards, and white-labeled end-user
> Experiences. Devices connect over MQTT 3.1.1 to broker.losant.com; everything else is a single unversioned
> REST API at https://api.losant.com. Losant ships a hosted, OAuth-protected MCP server at
> https://mcp.losant.com/mcp. Losant was acquired by SUSE.

Generated by API Evangelist on 2026-08-26. Losant does not publish an llms.txt of its own
(https://docs.losant.com/llms.txt and https://www.losant.com/llms.txt both return 404, probed 2026-08-26),
so this file is generated from the API Evangelist profile at https://apis.io/provider/losant.

## APIs

- [Losant Platform API](https://api.losant.com): One unversioned REST API covering every resource. Bearer JWT auth. 375 operations published in the provider's own schema document at https://api.losant.com/.
- [Application API](https://docs.losant.com/rest-api/application/): Applications, dashboards, events, webhooks, integrations, files, API tokens, certificates, audit logs, resource jobs.
- [Device API](https://docs.losant.com/rest-api/device/): Devices, device recipes, attributes, state, commands, payload counts.
- [Data and Data Tables API](https://docs.losant.com/rest-api/data/): Time-series queries, last-value queries, data tables and rows, bulk export.
- [Workflow Engine API](https://docs.losant.com/rest-api/flow/): Workflows, flow versions, node palette, virtual buttons, workflow storage, errors.
- [Experience API](https://docs.losant.com/rest-api/experience/): Views, endpoints, users, groups, versions, slugs, custom domains.
- [Edge and Embedded Compute API](https://docs.losant.com/rest-api/edge-deployment/): Edge and embedded deployments for gateways and microcontrollers.
- [Notebooks API](https://docs.losant.com/rest-api/notebook/): Jupyter-style notebook execution over application data.
- [Enterprise Instance API](https://docs.losant.com/rest-api/instance/): Administration of dedicated and self-hosted instances - orgs, members, tokens, custom nodes, notification rules, audit logs.
- [Authentication and Account API](https://docs.losant.com/rest-api/auth/): User and device authentication, tokens, profile, organizations.

## Agent surfaces

- [Losant MCP Server (hosted)](https://mcp.losant.com/mcp): Streamable HTTP MCP endpoint, OAuth 2.0 gated. Tools: losant_query, losant_write, losant_timeseries.
- [Losant MCP Server docs](https://docs.losant.com/mcp/overview/)
- [Losant MCP Server source](https://github.com/Losant/losant-mcp-server): MIT; also runnable locally (Docker image losant/losant-mcp-server) with a User API Token.
- [OAuth Authorization Server Metadata](https://api.losant.com/.well-known/oauth-authorization-server): RFC 8414 - issuer, endpoints, PKCE S256, 7 scopes.
- [OAuth Protected Resource Metadata](https://mcp.losant.com/.well-known/oauth-protected-resource): RFC 9728.
- No A2A agent card is published on any Losant host (probed 2026-08-26).
